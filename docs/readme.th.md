# TermAssist — ผู้ช่วยเทอร์มินัล

* ผู้พัฒนา: Peera Pilarit
* รุ่น: 1.0.1
* ใช้กับ NVDA: 2026.1 ขึ้นไป (ทดสอบกับ 2026.3)
* ซอร์สโค้ดและแจ้งปัญหา: https://github.com/9Peera/termAssist

TermAssist ช่วยให้ทำงานบนเซิร์ฟเวอร์ Linux (เช่น Ubuntu) ผ่านโปรแกรมเทอร์มินัลด้วย NVDA ได้สะดวกขึ้น ทั้งการอ่านผลลัพธ์ การพิมพ์และแก้ไขคำสั่ง และการค้นหาคำสั่งที่ต้องใช้บ่อยจากคลังคำสั่งภาษาไทยและอังกฤษ

## โปรแกรมที่รองรับ

* PuTTY, KiTTY, PuTTYtel
* PuTTY ที่ฝังอยู่ใน MTPuTTY และ SuperPuTTY
* Windows Terminal และคอนโซลของ Windows (cmd, PowerShell) เช่น เมื่อใช้คำสั่ง `ssh`
* MobaXterm และโปรแกรมอื่นที่เพิ่มชื่อไว้ในค่าตั้ง (แบบทดลอง)

## คำศัพท์พื้นฐาน

* **เซิร์ฟเวอร์:** คอมพิวเตอร์อีกเครื่องที่เราสั่งงานผ่านเครือข่าย
* **เทอร์มินัล:** หน้าต่างที่ใช้พิมพ์คำสั่งเป็นตัวอักษร เช่น หน้าต่าง PuTTY
* **Prompt:** ข้อความที่บอกว่าเซิร์ฟเวอร์พร้อมรับคำสั่ง เช่น `root@server:~#`
* **sudo:** คำที่ใส่หน้าคำสั่งเพื่อขอสิทธิ์ผู้ดูแลระบบ อาจถามรหัสผ่าน
* **โหมดคำสั่ง:** กด NVDA+Control+Shift+P แล้วกดตัวอักษรอีกหนึ่งตัวเพื่อสั่งงาน TermAssist

## เริ่มต้นใช้งาน

### ตั้งภาษาไทย

1. กด NVDA+Control+G เพื่อเปิดการตั้งค่า NVDA (NVDA Settings)
2. ในรายการหมวด เลือก **TermAssist**
3. ที่ช่อง **Language / ภาษา** เลือก **ไทย (Thai)** แล้วกด **ตกลง (OK)**

### ตั้ง PuTTY ให้แสดงภาษาไทยถูกต้อง

1. เปิด PuTTY ไปที่หมวด **Window** แล้วเลือก **Translation**
2. ที่ช่อง **Remote character set** เลือก **UTF-8**
3. กลับไปหมวด **Session** เลือก **Default Settings** แล้วกด **Save**

## โหมดคำสั่ง

เมื่ออยู่ในเทอร์มินัล กด **NVDA+Control+Shift+P** จะได้ยินเสียงสั้น ๆ ปล่อยทุกปุ่มแล้วกดปุ่มเดียวตามตาราง

| ปุ่ม | การทำงาน |
|---|---|
| H | แสดงรายการปุ่มทั้งหมด |
| 1 – 9 | อ่านบรรทัดที่ 1–9 นับขึ้นไปจาก prompt |
| Shift+1 – 9 | คัดลอกบรรทัดนั้น |
| L | สรุปผลคำสั่งล่าสุด (จำนวนบรรทัด และจำนวนบรรทัดที่เป็นข้อผิดพลาด) |
| O | เปิดหน้าต่างดูผลลัพธ์ของคำสั่งล่าสุด |
| Shift+O | เปิดประวัติทั้งหมด |
| R | อ่านคำสั่งที่พิมพ์ค้างอยู่ |
| E | แก้ไขคำสั่งในบรรทัดปัจจุบันด้วยช่องแก้ไขปกติ |
| M | เขียนข้อความหลายบรรทัด หรือเขียนลงไฟล์ |
| C | เปิดคลังคำสั่ง |
| S | ข้อมูลเซสชัน (ผู้ใช้ เครื่อง โฟลเดอร์) |
| P | สถานะของ nano, vim, โหมดอ่านทีละหน้า, top, htop |
| T / B | อ่านบรรทัดบนสุด / ล่างสุดของหน้าจอ |
| A | เปิด/ปิดเสียงแจ้งคำสั่งเสร็จ |
| D | รายงานวินิจฉัย (คัดลอกไปคลิปบอร์ดอัตโนมัติ) |
| Esc | ออกจากโหมดคำสั่ง |

ปุ่มอื่นจะออกจากโหมดคำสั่งพร้อมเสียงต่ำ ทุกคำสั่งกำหนดปุ่มลัดตรงได้ที่ เมนู NVDA > ค่าตั้ง (Preferences) > ปุ่มคำสั่ง (Input gestures) > หมวด TermAssist

ปิดหน้าต่างดูผลลัพธ์หรือหน้าช่วยเหลือด้วยปุ่ม Escape ในหน้าต่างดูผลลัพธ์ใช้ลูกศรอ่าน และกด NVDA+Control+F เพื่อค้นหา

## เสียงและการแจ้งอัตโนมัติ

* **เสียงแหลมสั้น:** คำสั่งทำงานเสร็จ ถ้าอยู่หน้าต่างอื่นจะพูดบอกด้วย
* **เสียงต่ำ:** ผลลัพธ์มีข้อผิดพลาด เช่น error, failed, denied, not found
* **เสียงสองจังหวะ:** เจอช่องให้ป้อนรหัสผ่าน NVDA จะหยุดอ่านตัวอักษรที่พิมพ์ชั่วคราว และกลับมาอ่านตามปกติเมื่อผ่านช่องนั้นแล้ว
* **โปรแกรมเต็มจอ:**
  * nano: บอกเมื่อเปิด และอ่านข้อความสถานะ เช่น `[ Wrote 12 lines ]`
  * vim: บอกโหมดเมื่อเปลี่ยน
  * less/man: บอกเมื่อถึงท้ายเอกสาร

## แก้ไขคำสั่ง (ปุ่ม E)

พิมพ์คำสั่งค้างไว้โดยยังไม่กด Enter แล้วกดปุ่ม E คำสั่งจะเปิดในช่องแก้ไขที่ NVDA อ่านได้ครบ แก้เสร็จแล้วเลือก:

* **แทนที่ (Replace):** ใส่คำสั่งที่แก้แล้วกลับเข้าไปโดยยังไม่รัน
* **แทนที่และรัน (Replace and run):** ใส่แล้วรันทันที

## เขียนข้อความหลายบรรทัดหรือเขียนไฟล์ (ปุ่ม M)

* **คำสั่ง (Commands):** แต่ละบรรทัดคือหนึ่งคำสั่ง ส่งไปรันทั้งหมด
* **เนื้อหาของไฟล์ (Content of a file):** ใส่ตำแหน่งไฟล์ แล้วเลือกเพิ่มเติมได้:
  * **ใช้ sudo:** สำหรับไฟล์ระบบ
  * **ต่อท้ายไฟล์เดิม:** ถ้าไม่เลือก จะเขียนทับไฟล์เดิม

## คลังคำสั่ง (ปุ่ม C)

มีคำสั่งพื้นฐาน 163 คำสั่งใน 15 หมวด และชุดบริการอีก 13 ชุด

1. พิมพ์คำค้นหาเป็นภาษาไทยหรืออังกฤษ แล้วกดลูกศรลงไปที่รายการ
2. เลือกคำสั่ง ช่องรายละเอียดจะบอกคำสั่งจริง หมวด ระดับความเสี่ยง และค่าที่ต้องกรอก
3. กดปุ่มที่ต้องการ:
   * **แทรก (Insert / Enter):** พิมพ์คำสั่งลงไปโดยยังไม่รัน
   * **รัน (Run):** พิมพ์แล้วรันทันที
   * **คัดลอก (Copy):** คัดลอกคำสั่งไปคลิปบอร์ด
4. ถ้าคำสั่งต้องการค่า เช่น ชื่อไฟล์หรือชื่อบริการ จะมีช่องถามทีละค่า

**เลือกค่าจากเซิร์ฟเวอร์:** ช่องที่บอกว่า "เว้นว่างแล้วกด ตกลง เพื่อเลือกจากรายการบนเซิร์ฟเวอร์" ถ้าเว้นว่างแล้วกด ตกลง ส่วนเสริมจะรันคำสั่งดึงรายการแล้วให้เลือกด้วยลูกศร

* ต้องอยู่ที่ prompt ก่อน
* คำสั่งที่ใช้ดึงรายการจะปรากฏบนหน้าจอด้วย
* ถ้ารายการว่าง จะบอกเหตุผล เช่น ยังไม่ได้ติดตั้งโปรแกรม ไม่มีโฟลเดอร์ ไม่มีสิทธิ์ หรือบริการไม่ทำงาน

**ความปลอดภัย:**

* คำสั่งความเสี่ยงสูง เช่น ลบไฟล์ หรือรีบูตเครื่อง ต้องยืนยันก่อนรัน
* ไม่มีการส่งคำสั่งที่มีค่าว่าง

**รายการโปรดและคำสั่งของฉัน:** กดปุ่ม **เพิ่มในรายการโปรด** หรือ **เพิ่มคำสั่งใหม่** ได้ ข้อมูลเก็บที่ไฟล์ `termAssist.json` ในโฟลเดอร์ค่าตั้งของ NVDA

### หมวดคำสั่งพื้นฐาน

ข้อมูลระบบ, ไฟล์และโฟลเดอร์, ดูเนื้อหาไฟล์, แก้ไขไฟล์, ผู้ใช้และสิทธิ์, แพ็กเกจ (apt), บริการ (systemd), ทรัพยากรและโปรเซส, เครือข่าย, ไฟร์วอลล์และความปลอดภัย, Log, บีบอัด สำรอง และโอนไฟล์, ดิสก์, ตั้งเวลางาน, เว็บ ฐานข้อมูล และคอนเทนเนอร์

### ชุดบริการ (Service Packs)

Docker / Compose, Nginx, Apache, MySQL / MariaDB, PostgreSQL, PHP / PHP-FPM, Redis, Certbot (SSL), Git, Node.js / PM2, Python / venv, Fail2ban, Samba

ทุกชุดแบ่งกลุ่มเหมือนกัน: ตรวจการติดตั้งและเวอร์ชัน, สถานะ, เริ่ม/หยุด/รีสตาร์ท, Log, ทดสอบค่าตั้ง, ไฟล์ค่าตั้ง, งานที่ทำบ่อย, แก้ปัญหา

* **ตรวจหาบริการในเครื่อง:** ครั้งแรกที่ใช้คำสั่งของชุดบริการบนเครื่องใด ส่วนเสริมจะตรวจให้อัตโนมัติ หรือกดปุ่ม **ตรวจหาบริการในเครื่อง** เองก็ได้ หมวดของบริการที่มีในเครื่องจะขึ้นก่อน
* **ถ้ายังไม่ได้ติดตั้งบริการนั้น:** จะถามว่า ติดตั้ง / ใช้คำสั่งต่อ / ยกเลิก

## ค่าตั้ง

กด NVDA+Control+G แล้วเลือกหมวด TermAssist

* ภาษา (ตาม NVDA / ไทย / อังกฤษ)
* เสียงแจ้งคำสั่งเสร็จ และบอกจำนวนบรรทัด
* แจ้งเมื่อคำสั่งเสร็จในเทอร์มินัลที่ไม่ได้โฟกัสอยู่
* เสียงแจ้งข้อผิดพลาด
* ปิดเสียงตัวอักษรที่พิมพ์เมื่อป้อนรหัสผ่าน
* บอกสถานะ nano, vim และโหมดอ่านทีละหน้า
* วิธีส่งข้อความ: วางผ่านคลิปบอร์ด หรือพิมพ์โดยตรง (เฉพาะกลุ่ม PuTTY)
* ปุ่มล้างบรรทัดคำสั่ง (ค่าเริ่มต้น Control+E, Control+U สำหรับ bash)
* Regex ของ prompt แบบกำหนดเอง
* โปรแกรมเทอร์มินัลอื่น (แบบทดลอง)
* ความถี่ในการตรวจหน้าจอ และขนาดประวัติ

## ข้อควรรู้

* ตอนส่งข้อความด้วยวิธีวางผ่านคลิปบอร์ด ส่วนเสริมจะใช้คลิปบอร์ดชั่วคราว แล้วคืนข้อความเดิมให้ภายในประมาณ 1 วินาที
* โปรแกรมเต็มจอ เช่น htop และ nano จะไม่ถูกบันทึกลงประวัติ
* Windows Terminal อ่านเฉพาะบรรทัดที่มองเห็น ผลลัพธ์ที่เลื่อนผ่านเร็วมากอาจไม่ครบในประวัติ
* การบอกเหตุผลเมื่อรายการว่างต้องใช้ shell แบบ bash (ค่าเริ่มต้นของ Ubuntu)
* ถ้ามีส่วนเสริมอื่นที่ทำงานกับ PuTTY อยู่ด้วยแล้วเจออาการแปลก ให้ลองปิดส่วนเสริมนั้นชั่วคราว
